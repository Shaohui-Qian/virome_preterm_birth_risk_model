# virome_preterm_birth_risk_model
母体妊娠队列研究分析代码，探究人口学、产科因素、妊娠期合并症、甲状腺疾病以及病毒组感染与早产发生风险的多元logistic回归分析，输出森林图展示各危险因素OR值与95%置信区间。
# 研究概述
以早产作为二分类结局，采用逐步校正的多元Logistic回归，依次纳入人口学、产科病史、妊娠合并症、甲状腺相关疾病，再引入病毒感染指标，评估病毒组感染对早产的关联效应。同时分别开展单一病毒感染、病毒阳性（单一病毒+共感染）的亚组分析。
# 模型设置
Model1 基础模型：校正母亲年龄、BMI
Model2 产科校正模型：在Model1基础上，校正孕次、既往早产史
Model3 合并症校正模型：在Model2基础上，校正妊娠期高血压、妊娠期高血糖、自身免疫性甲状腺炎、甲减/亚临床甲减、甲亢/亚临床甲亢、低T4血症
Model4 全校正模型：Model3全部协变量 + 总体病毒感染状态，评估整体病毒感染和早产的关联
Model5 单一病毒感染亚组分析
病例限定为仅感染该目标病毒、排除其他病毒共感染样本；对照组为无任何病毒感染对象；校正其他临床混杂因素，用于评估单纯某一种病毒感染与早产的关联。共感染个体在该模型中剔除。
Model6 病毒阳性亚组分析（允许共感染）
病例组为目标病毒阳性个体，允许存在其他病毒共感染；对照组为无病毒感染对象；校正全套临床混杂因素。该模型保留共感染样本，效应包含共感染带来的混杂。
# 缺失处理
病毒检测指标的缺失值赋值为0，视为未感染。
